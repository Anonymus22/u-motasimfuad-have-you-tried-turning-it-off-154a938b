One funny line a hopeless tech support agent says to a desperate customer:

> Have you tried turning it off and on again? I ask because that's also my entire plan for the rest of this call.

## Run

```sh
node main.ts
```

This writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
